1. Direct Document Errata (Answer Key Typos in Original PDF)

Q26 Erratum Section A • AI Industry Use Cases

Which AI industry application does NVIDIA DRIVE target?

Document Marked Answer: [C] Financial trading

Typo in the document's answer key.

Verified Correct Answer: [B] Autonomous vehicles

Confirmed by NVIDIA DRIVE SDK, DriveOS, and the document's own explanation.

Audit Rationale: The PDF's explanation explicitly states: "NVIDIA DRIVE provides hardware and software for autonomous vehicle AI." The author inadvertently stamped option C. Corrected in this simulator.

Q107 Erratum Section B • Data Centre Power & Redundancy

What is N+1 redundancy in data centre power and cooling?

Document Marked Answer: [C] Fully redundant 2N systems...

Option C describes 2N (dual-path) redundancy, not N+1.

Verified Correct Answer: [B] One additional capacity component...

Standard Uptime Institute definition of N+1 redundancy.

Audit Rationale: The explanation confirms: "N+1 means one extra unit; if any single unit fails, the remaining N units handle the load." Option B matches this. Corrected in this simulator.

2. Technical Nuances & Author Oversimplifications

Q67 DGX A100 System Power Draw

What is the primary reason DGX A100 has higher power consumption (~15 kW) than many standard servers?

Technical Note: The prompt mentions (~15 kW). In official NVIDIA hardware specs, a single 4U DGX A100 draws a maximum of 6.5 kW (6500 W), not 15 kW. 15 kW is representative of a fully populated multi-server rack. The correct answer remains [B] because the eight 400W GPUs and dual CPUs are the dominant power consumers.

Q194 BlueField DPU Architecture

Which NVIDIA product was purpose-built for joint CPU+GPU computing to handle both AI inference and data centre infrastructure offload on the same chip?

Technical Note: Marked as [C] NVIDIA BlueField DPU. Strictly speaking, BlueField DPUs house ARM CPU cores and ConnectX networking silicon, but not a full GPU on-die (NVIDIA Grace Hopper GH200 is the CPU+GPU superchip). BlueField offloads network and storage infrastructure. Among the choices (A100, Jetson, BlueField, Quadro), BlueField was chosen by the author.

Q233 NVIDIA NIM Scope

Which NVIDIA tool manages the lifecycle of AI models from development through production, integrating with popular experiment tracking frameworks?

Technical Note: Marked as [B] NVIDIA NIM. NIM specifically stands for NVIDIA Inference Microservices, which containerizes and serves models with standard APIs. Full experiment tracking is typically MLflow or Base Command Manager, but NIM is the author's target answer.

1. The NVIDIA AI Software Stack (Bottom to Top)

The exam frequently asks about the role of each layer and the order of execution:

Layer 1

CUDA

Parallel computing platform; base OS/kernel layer for all GPU programming.

Layer 2

cuDNN & cuBLAS

GPU-accelerated deep learning primitives and BLAS linear algebra library.

Layer 3

Frameworks

PyTorch, TensorFlow, JAX; environment where neural networks are constructed.

Layer 4

TensorRT

Inference optimizer SDK; fuses layers, quantizes (FP8/INT8/FP16) for 2–5x lower latency.

Layer 5

NGC Catalog

Free public hub for optimized container images, pre-trained models, and Helm charts.

Layer 6

AI Enterprise

Enterprise management platform with production SLAs, VMware/Red Hat support.

DGX H100 System Architecture

  • • 8x H100 SXM5 GPUs: 640 GB total aggregate HBM3 memory.
  • • NVLink 4.0 + 4x NVSwitches: 900 GB/s bidirectional per GPU (3.6 TB/s aggregate per GPU).
  • • CPUs & Memory: Dual Intel Xeon Platinum CPUs, 2 TB DDR5 system memory.
  • • Networking: 8x ConnectX-7 high-speed ports (400 Gbps InfiniBand NDR or 100 GbE) for compute.
  • • Out-of-band BMC: 1x 1 GbE RJ45 dedicated management port (NOT for compute traffic).
  • • Power: ~10.2 kW max power consumption (requires 3-phase power delivery).

DCGM & Observability Cheat Sheet

  • • DCGM: Data Center GPU Manager for cluster monitoring, profiling, and health checks.
  • • SBE vs DBE: Single-Bit ECC errors (SBE) are correctable. Double-Bit ECC errors (DBE) are uncorrectable and indicate immediate hardware replacement.
  • • Thermal Throttling: Begins around ~83°C on modern Hopper/Ampere data center GPUs.
  • • Prometheus Export: Uses dcgm-exporter to export metrics into Grafana dashboards.
  • • Slurm vs K8s: Slurm is optimized for static HPC batch training; Kubernetes GPU Operator is standard for microservices and real-time inference serving.
